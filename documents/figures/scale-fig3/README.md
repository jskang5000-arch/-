## PPT 배치 제안

탁도와 주파수·전압 영향을 설명하는 장에는 (a)와 (b), 표면 부착 억제를 설명하는 장에는 (d)와 필요시 (e)의 SEM 사진을 넣으면 글자와 범례를 크게 유지할 수 있다. (c)는 전도도·pH 변화 자체를 설명할 때 사용한다.

주의: (a)·(b)의 탁도 축은 로그 눈금이다. 오차막대는 원문에 따라 3회 반복(N=3)의 표준편차다. 탁도는 용액 내 결정 형성의 지표, 피복률은 판 표면 부착의 지표이며 두 값을 가열효율이나 부식 감소율로 바꾸지 않는다.
